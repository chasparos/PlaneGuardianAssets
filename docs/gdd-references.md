# PlaneGuardian GDD References

PlaneGuardianAssets consumes design contracts from the sibling
`PlaneGuardianGDD` repository without copying or redefining their authority.

- `Technical/Semantic_Procedural_Asset_Architecture.md` — semantic resolution,
  paired delivery, generator SPI, material roles, and versioning.
- `Decisions/DD-0021-semantic-procedural-asset-runtime.md` — accepted procedural
  runtime decision and Great Tree reference generator.
- `Art/Production_Guides/Land_and_Attachment_Visual_Contract.md` — visual
  ownership, host integration, detail budget, and camera-scale review.
- `Art/Production_Guides/Attachment_Slots.md` — stable foundations, attachment
  identity, host contact, and slot validation.
- `Procedural/Lore_Map_and_Affinity_Wheels.md` and linked wheel documents —
  semantic authority whenever adapter mapping is ambiguous.

These are design inputs, not source dependencies. Reconcile changes explicitly
and record versions rather than reading the GDD dynamically at runtime.
